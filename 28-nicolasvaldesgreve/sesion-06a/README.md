## apuntes sesión

``Uint duracionPresionado`` -> la U dice 0,1,2,3... pero se salta los negativos, ya que ``u`` significa unsigned (sin signo), por lo que cuenta solo los números positivos lolololol.

``float`` -> lugar de infinita resolución, cuenta con decimales. 

``...`` -> variable (datos en humano), dentro de una clase se le llama _atributos_.

``...()`` -> funciones (acciones en humano), dentro de una clase se le llama _método_.

``class`` -> lo que viene no es una variable, es una estructura de información. al ser clase, tiene una mayúscula al inicio (si no hay mayúscula, no es una clase).

#### ejemplo de clase con perrites

```cpp
class Perrite{

bool hambre = true;
bool durmiendo = true;
int pelaje = #000000; // estos son los atributos kkkkkkk

comer ();
dormir ();
cagar (); // estos son los métodos 

}
```

``superclass`` = subvariedad de algo, como por ejemplo:

```cpp
class Poodle{

superclass Perrite();
bool molestando = true ;

}
```
