## Lectura

**Resumen:**

Comienzo en la pág. 39, donde se explica el funcionamiento de la red inalámbrica. Se menciona que esta función está disponible en Raspberry Pi 3, Raspberry Pi 4 y Raspberry Pi Zero W. En caso de utilizar otro modelo de Raspberry Pi, será necesario contar con un adaptador USB para conectarse mediante Wi-Fi.

También se explica que es posible conectarse a una red inalámbrica a través de un router o elegir no conectarse a ninguna red. Además, se menciona la importancia de las actualizaciones, ya que mediante estas Raspberry Pi OS puede corregir errores y mantener el sistema actualizado.

En la pág. 40 se explica que, si el sistema lo solicita, es necesario reiniciar la Raspberry Pi. Después de hacer esto, el asistente de instalación ya no volverá a aparecer, debido a que la configuración inicial estará terminada. Luego aparecerá el escritorio, el cual cuenta con funciones similares a las que ya conocemos de los escritorios de otros sistemas operativos.

En la pág. 41 se mencionan los diferentes menús y widgets disponibles en el escritorio. Por ejemplo, el reloj permite acceder al calendario y también existen botones relacionados con funciones como Bluetooth. Además, si se utiliza una memoria externa, esta puede expulsarse de forma segura mediante una opción disponible en la barra.

También se explica que “en el lado izquierdo de la barra se encuentra el menú de iniciadores”. Desde esta zona se puede acceder a diferentes programas instalados en el sistema, algunos de los cuales no aparecen directamente en el escritorio. Para acceder al menú principal se debe hacer clic en el ícono de una frambuesa, ya que “raspberry” significa frambuesa en inglés.

En la siguiente página se menciona Chromium, un navegador que funciona de manera similar a Google Chrome y que, en términos generales, sirve para realizar las mismas funciones relacionadas con la navegación por Internet.

También se destaca la importancia de guardar cada proyecto antes de cerrar cualquier aplicación. Esto se debe a que algunas aplicaciones pueden advertir cuando existen cambios sin guardar, mientras que otras pueden cerrarse sin mostrar ninguna advertencia.

Finalmente, hasta la pág. 46 se explica cómo utilizar el gestor de archivos y algunas de sus funciones principales. También se mencionan diferentes atajos de teclado, como copiar, pegar y cortar, que permiten trabajar de una manera más rápida.

Además, se presenta LibreOffice, un paquete de productividad que cumple funciones similares a Microsoft Office o Google Docs. Sin embargo, se menciona que LibreOffice no viene preinstalado en todos los sistemas Raspberry Pi.
